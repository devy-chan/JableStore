JABLE STORE - ONLINE HOSTING SETUP
==================================

This package is prepared for PHP + MySQL hosting. It is NOT for GitHub Pages.

1. CREATE A MYSQL DATABASE
   In your hosting control panel, create a MySQL/MariaDB database.
   Record these four values:
     - Database Host
     - Database Username
     - Database Password
     - Database Name

2. IMPORT THE DATABASE
   Open the host's phpMyAdmin.
   Select the database you created.
   Import:
     database/store.sql

3. EDIT DATABASE CONNECTION
   Open:
     backend/config/db_connect.php

   Replace:
     YOUR_DATABASE_HOST
     YOUR_DATABASE_USERNAME
     YOUR_DATABASE_PASSWORD
     YOUR_DATABASE_NAME
     YOUR-DOMAIN

   Example only:
     $localhost = "sql123.examplehost.com";
     $username  = "user123_store";
     $password  = "YOUR_REAL_PASSWORD";
     $dbname    = "user123_store";
     $store_url = "https://yourstore.example.com/";

4. UPLOAD THE PROJECT
   Upload the CONTENTS of this jablestore folder to your hosting web root
   (commonly public_html, htdocs, or a similar folder).

   The online root should contain:
     index.php
     frontend/
     backend/
     assests/
     custom/
     libraries/

5. TEST THE STORE
   Open:
     https://YOUR-DOMAIN/

   The root index.php redirects to:
     frontend/store/index.php

6. TEST ADMIN
   Open:
     https://YOUR-DOMAIN/backend/admin/login.php

7. SECURITY
   - Change the default admin password immediately after first login.
   - Do not publish database credentials in GitHub.
   - Keep database/store.sql protected; this package includes a database/.htaccess rule.
   - Enable HTTPS/SSL in your hosting control panel.

8. IF THE HOST USES A SUBFOLDER
   If your website is at something like:
     https://example.com/jablestore/
   then set:
     $store_url = "https://example.com/jablestore/";

9. IMPORTANT
   GitHub Pages cannot execute the PHP/MySQL backend. Use PHP/MySQL hosting
   for the live JABLE STORE website. GitHub may still be used to store the
   source code and collaborate with your friend.
