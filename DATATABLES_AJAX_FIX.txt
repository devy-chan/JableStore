DataTables AJAX fix

All backend action include paths now use __DIR__ so they resolve correctly regardless of the Apache working directory.

The Categories, Brand, and Product fetch endpoints now return a JSON error with the MySQL error and HTTP 500 if their SQL query fails, instead of producing an HTML/PHP fatal response that DataTables reports only as Ajax error.

Test endpoints while logged in:
/jablestore/backend/actions/fetchCategories.php
/jablestore/backend/actions/fetchBrand.php
/jablestore/backend/actions/fetchProduct.php

Expected response begins with {"data":[...]} when successful.
