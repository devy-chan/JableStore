# JABLE STORE — GitHub Pages Version

This folder is a **static GitHub Pages demo** of JABLE STORE.

## Included
- Home/storefront
- Product browsing and search
- Categories and price sorting
- Product detail pages
- Browser-based cart
- Demo checkout
- Demo order confirmation
- Existing JABLE styling and product images

## Important limitation
GitHub Pages does not execute PHP and does not provide MySQL. Therefore this version does **not** use the original PHP admin panel or MySQL database.

Orders created here are demo orders stored only in the visitor's browser.

For a real online store, keep the PHP/MySQL backend on a PHP-capable server and connect this frontend to it with HTTPS API endpoints.

## Publish
1. Create a public GitHub repository named `JableStore`.
2. Upload everything in this folder to the repository root.
3. GitHub → Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main`; folder: `/ (root)`.
6. Save and open the generated GitHub Pages URL.
